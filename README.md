## Второй этап — инкрементальный анализ (текущий)

### Что добавлено

- **Модуль `app/incremental/`** — инкрементальный анализ
  - `cache.py` — трёхуровневый кэш (AST, результаты, граф зависимостей)
  - `import_graph.py` — граф зависимостей между модулями
  - `diff_resolver.py` — определение изменённых файлов через git diff
  - `incremental_analyzer.py` — оркестратор с 4 режимами

- **CLI (`cli.py`)** — 4 режима работы:
  - `--full` — полный анализ проекта
  - `--working` — анализ незакоммиченных изменений
  - `--staged` — анализ staged файлов (pre-commit)
  - `--incremental` — анализ изменений в PR (CI/CD)

- **CI/CD интеграция:**
  - `.github/workflows/security.yml` — GitHub Actions
  - `.pre-commit-config.yaml` — pre-commit hook
  - `Dockerfile` + `docker-compose.yml`

- **Тесты и benchmark:**
  - Проверка корректности (MATCH)
  - Замер производительности
