# Результаты работы нашего SAST-анализатора

## Тестовый файл: complex_test.py

### Обнаружено уязвимостей: 4

#### 1. SQL Injection (Critical) 🔴
- **Местоположение:** Строка 29 (`cursor.execute(query)`)
- **Описание:** Данные из HTTP GET параметра попадают в SQL-запрос без очистки.
- **Путь данных:** `request.args.get('id')` → `self.current_user` → `query` → `cursor.execute`
- **Ключевая особенность:** Уязвимость найдена благодаря межпроцедурному анализу (трекинг `self.attr` между методами `login` и `get_profile`).
- **Уверенность:** 95%

#### 2. XSS (Reflected) (Critical) 🔴
- **Местоположение:** Строка 44 (`render_template`)
- **Описание:** Пользовательский ввод из формы передается в шаблонизатор без экранирования.
- **Путь данных:** `request.form.get('name')` → f-string → `render_template`
- **Уверенность:** 95%

#### 3. Hardcoded Secret (Critical) 🔴
- **Местоположение:** Строка 9
- **Описание:** Обнаружен захардкоженный API ключ.
- **Рекомендация:** Используйте переменные окружения (.env).
- **Уверенность:** 85%

#### 4. Weak Cryptographic Hash (Medium) 🟡
- **Местоположение:** Строка 19 (`hashlib.md5`)
- **Описание:** Использование небезопасного алгоритма хеширования MD5.
- **Рекомендация:** Используйте SHA-256 или bcrypt.
- **Уверенность:** 85%

---
**Примечание:** В отличие от Bandit, наш анализатор успешно обнаружил межпроцедурную SQL-инъекцию, которую стандартные инструменты часто пропускают из-за отсутствия трекинга состояния классов (`self.*`).
